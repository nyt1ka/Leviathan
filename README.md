# AgroHelper / АгроФронт — v1.0 Beta

Это крупная сборка, чтобы не загружать десятки мелких обновлений.

## Уже готово

- современный интерфейс;
- светлая и тёмная тема;
- калькуляторы:
  - рабочий раствор;
  - препарат;
  - замесы;
  - вылеты;
  - производительность;
  - среднее время АКБ;
- каталог техники DJI / XAG / HD Huida;
- фотографии и подробные характеристики;
- «Новая работа»;
- выбор дрона;
- выбор сохранённого поля;
- готовый план обработки;
- локальный журнал;
- сохранение и удаление работ;
- раздел «Поля»;
- локальное сохранение полей;
- справочники;
- настройки значений по умолчанию;
- запоминание последнего дрона;
- GitHub Actions для автоматической сборки debug APK после загрузки проекта.

## Важно

Это beta-версия. Архитектура рассчитана на дальнейшее развитие без необходимости
каждый раз полностью переделывать проект.

После загрузки проекта GitHub Actions автоматически запустит тесты и сборку APK.
APK появится в Artifacts у workflow run.

Версия: 1.0.0-beta
Минимальный Android: 8.0 (API 26).
