# AgroHelper / АгроФронт

## v0.5.0 — новый интерфейс

Полный Android-проект с переработанным интерфейсом.

### Что изменено

- единый современный стиль;
- аграрная палитра: зелёный, золотой, тёплый кремовый фон;
- поддержка светлой и тёмной темы;
- крупные и понятные карточки на главном экране;
- иконки для основных разделов;
- калькуляторы разделены на понятные блоки;
- результаты визуально отделены от полей ввода;
- каталог техники получил более аккуратные карточки;
- характеристики дронов показаны компактнее;
- фото, фильтры и поиск сохранены;
- кнопка «Использовать в калькуляторе» сохранена;
- экраны-заглушки тоже оформлены в общем стиле.

Версия: 0.5.0
Минимальный Android: 8.0 (API 26).
