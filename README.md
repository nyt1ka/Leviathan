# AgroHelper / АгроФронт

Первая офлайн-версия Android-приложения для эксплуатантов агродронов.

## Уже реализовано в v0.1
- главный экран;
- раздел «Калькуляторы»;
- количество рабочего раствора;
- количество препарата;
- количество замесов;
- количество вылетов;
- производительность, га/ч;
- среднее фактическое время работы АКБ;
- полностью локальные расчёты без сервера и интернета.

## Следующий этап
- раздел «Техника»;
- справочник DJI Agras;
- справочник XAG;
- справочник HD / Huida Tech;
- выбор модели дрона с автоматической подстановкой объёма бака;
- локальное хранение данных;
- поля;
- журнал работ.

## Открытие проекта
1. Распакуйте архив.
2. Откройте папку AgroHelper в Android Studio.
3. Дождитесь Gradle Sync.
4. Запустите на Android-устройстве или эмуляторе.

Минимальная версия Android: 8.0 (API 26).
